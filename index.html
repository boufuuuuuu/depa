          DEPA FX SYSTEM

          ENTRY CONSOLE v3.2 — 建玉設計コンソール。

          v3.1.1では、銘柄/時間足変更直後の再計算、Edge Factorのtrue/false/null全状態保存、同一Evidence母集団でのON/OFF比較、MTF Edgeの鮮度確認、Stress仮定のWATCH Signature除外を追加しています。旧v3.1 Journalの発火ID欠落はOFFへ推定せずUnknownとして扱います。

          v3.1.2では、LONG/SHORT別の勝率・負率、本日/トータルの獲得pips・獲得金額、Entry時間帯別の獲得pips・金額をJournal Analyticsへ追加しています。pipsは実約定価格差、金額は実現金額入力を優先し未入力時のみ実現R×保存Riskを使用します。本日はExit日時、時間別はEntry日時で判定します。

          v3.2では、Edge Discoveryとして単独Factorと2/3 Factor組み合わせのON/OFF比較・前半/後半Δ、Journal保存時の数値スナップショット、Observed Playbookの自動言語化、Declared Methodの構造化保存、Declared vs Observed一致率を追加しています。組み合わせランキングは探索用で、自動Edge採用や因果推論は行いません。

          Phase 2では、入力の端末内自動保存と、ユーザー定義のBroker/銘柄Presetを追加しています。Presetは銘柄仕様とBroker/Risk関連設定だけを保存し、残高・現在値・ATR・SwingはPresetには含めません。

          Phase 3では、複数の建玉設計をRisk予約として保存し、名目総リスク・登録時証拠金合計・FX通貨方向の集中を管理します。Portfolioへの登録は約定確認ではありません。

          Phase 4では、建玉設計をTrade Journalへ保存し、Status・実現R・メモを記録できます。集計は保存された実績だけを対象にし、未入力の実現Rを推定しません。

          Phase 5では、ホーム画面追加・standalone表示・Service Workerによるオフライン起動を追加しています。外部データ取得が必要な機能はオフライン利用の対象外です。

          Phase 6では、Current / Entry / SL / TP / BE / Add / 平均建値 / GRID各段を同一価格軸へ配置するPosition Mapを追加しています。ローソク足や未取得の値動きは描画しません。

          Phase 7では、ユーザー自身のTwelve Data API Keyを使った現在値とOHLC取得、Wilder ATRのローカル計算を追加しています。M3は1分足を3本ずつ集約します。取得失敗時は手入力値を維持します。

          Phase 8では、現在セットアップのWATCH、ENTRY Zone到達、Entry価格Cross、Gate PASS/FAIL遷移、状態変化のAlert Historyと通知を追加しています。監視はアプリが開いている間の再計算時だけ行い、バックグラウンド常時監視は行いません。

          v2.8-P8.1ではM30を追加し、銘柄/時間足変更時にAPI Key設定済みなら現在値・ATR14・直近100本の最高High/最低Lowを自動取得します。取得値は基準値として既存入力欄へ入り、その後ブローカー値へ手修正できます。

          v2.9-P8.2では、銘柄のQuote通貨と口座通貨から必要な換算FXレートを自動判定し、USDJPY/EURUSD/GBPUSD/AUDUSD/NZDUSD/USDCAD/USDCHFのうち必要なものだけ取得します。API取得後の換算値は手修正でき、BROKER ADJUSTEDとして保持します。

          v2.10-P8.3では、銘柄と戦術画面の下部に選択中の銘柄・時間足の直近100本OHLCを使ったミニローソク足チャートを追加しています。現在値、Swing High 100、Swing Low 100も同じ価格軸に表示します。

          v2.11-P8.4では、ミニチャートへEMA20 / EMA50 / EMA200を重ね、下段へWilder方式のRSI13を追加しています。約350本を指標計算に使用し、チャート表示は直近100本に限定します。M3は1分足を3分足へ集約後に指標を計算します。

          v3.0ではData Quality Guard、Trade Lifecycle、Journal Analytics、Multi-Timeframe Dashboard、Scenario Stress Test、Backup/Restoreを追加しています。Data Qualityの初期STALE閾値は暫定値であり、ユーザー変更可能です。Stress TestはWhat-if仮定で損失上限を保証しません。

          これはシグナル発生器ではありません。入力された相場・口座・ブローカー条件から、ゲート判定、建玉サイズ、管理価格を計算します。Risk Engine v2では、SL・Spread・Commission・Slippageを合算した実リスクからLotを決定します。

          この配布物は、2007〜2009年頃の classic iUI のHTML構造・画面遷移・Settings風UIを再現するための、オフライン動作用互換レイヤーを同梱しています。元のiUIライブラリ本体は同梱していません。

          実運用前に、使用ブローカーの契約サイズ、tick/pip、証拠金計算、手数料、最小ロット、ロット刻み、ストップ制約を確認してください。特に指数・原油・暗号資産はブローカー間差が大きいため、銘柄仕様の確認を必須としています。
